# Cards Delivery — نظام تبادل الكارنيهات

نسخة جاهزة للرفع على GitHub وتشتغل على الاستضافة مباشرة من غير أي خطوات بناء.

## الملفات

| الملف | إيه اللي فيه |
|---|---|
| `texts.js` | ✅ **ده الملف اللي تعدّل فيه** — كل الكلام الظاهر في الموقع |
| `index.html` / `office.html` | صفحة الموقع |
| `app.js` | التطبيق نفسه (متلمسوش) |
| `admin.js` | نافذة «إدارة النظام» (الموظفين والفروع) |
| `lookup.js` | بحث رقم العضوية ومكان الفرع |
| `sync.js` | المزامنة بين الأجهزة |
| `favicon.png` | أيقونة التبويب |
| `vercel.json` | إعدادات الاستضافة |

## إزاي تعدّل أي كلام

1. افتح ملف **`texts.js`**.
2. كل سطر شكله كده:

   ```js
   "لوحة التحكم": "لوحة التحكم",
   ```

3. عدّل **الكلام اللي على اليمين بس** (بين علامتي التنصيص التانيين).
   مثال:

   ```js
   "لوحة التحكم": "الشاشة الرئيسية",
   ```

4. احفظ الملف وارفعه على GitHub — الكلام الجديد يظهر في اللينك على طول بعد تحديث الصفحة.

### قواعد مهمة

- متغيّرش الكلام اللي على **الشمال** أبدًا.
- متحذفش الفاصلة `,` في آخر السطر ولا علامات التنصيص `"`.
- تغيير **اسم فرع** أو **اسم حالة** بيغيّر الشكل بس؛ الطلبات القديمة المحفوظة بتفضل بالاسم القديم.
- لو الصفحة طلعت بيضا بعد تعديل، معناها فاصلة أو علامة تنصيص ناقصة — رجّع السطر زي ما كان.
